# Papilla's Physics

Sitio docente personal del profesor César Barrero, creado para organizar materiales, ejercicios, simulaciones y recursos relacionados con la enseñanza de la física.

El proyecto comienza con el curso Física Básica I y está preparado para crecer progresivamente con nuevos contenidos y herramientas docentes.

## Estado actual

Versión inicial de la identidad visual y la navegación del sitio.

Incluye:

- Portada responsive.
- Identidad visual de Papilla's Physics.
- Menú principal de pantalla completa.
- Submenú para Física Básica I.
- Página inicial con accesos destacados.
- Sección de avisos.
- Páginas provisionales para recursos, simulaciones y actividades.

El contenido académico y las herramientas interactivas continúan en desarrollo.

## Tecnologías

- Astro.
- HTML semántico.
- CSS.
- JavaScript.
- Node.js y npm.
- Git y GitHub.

El proyecto no utiliza React, Vue, Tailwind, backend ni base de datos en su estado actual.
